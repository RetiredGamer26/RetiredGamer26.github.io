# Studio Timelines — Game Franchise Tracker

A React + Vite + TypeScript frontend app that displays game studio timelines (starting with the Uncharted franchise). Uses shadcn/ui components, Tailwind CSS, and Wouter for routing.

## How to run

The workflow `Start application` runs `PORT=5000 npm run dev`, which starts the Vite dev server on port 5000.

## Stack

- React 18 + TypeScript
- Vite 5
- Tailwind CSS + shadcn/ui (Radix UI primitives)
- Wouter (client-side routing)
- Framer Motion (animations)
- TanStack Query

## Pages

- `/` — Home: studio timeline view
- `/disclaimer` — Disclaimer page
