# Theseus Games Timelines

A React + Vite + TypeScript app for exploring game studio timelines and founder status.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the Vite dev server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal (usually http://127.0.0.1:5173).

## Build for production

```bash
npm run build
```

## Notes

- The project was refactored from a Replit-specific setup to work with a standard local Vite environment.
- You can override the port with:
  ```bash
  PORT=5173 npm run dev
  ```
